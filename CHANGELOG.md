# Changelog


## [0.8.0]

Initial public preview.

- DeepSeek Harness plugin with a separate transparent, always-on-top desktop pet that
  reflects activity across chats.
- Clicking the pet brings Harness to the foreground on its last-open chat.
- User-facing text is available in English, Russian, and Simplified Chinese.
- The tested macOS desktop build is arm64; Intel is untested. Windows is untested.
- Starts the shell with Harness's OS-assigned loopback port.
